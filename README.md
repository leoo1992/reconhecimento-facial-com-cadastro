# Reconhecimento facial com cadastro

Aplicação de estudo que combina cadastro e reconhecimento facial com um servidor Node.js/Express. O backend expõe endpoints HTTP para a interface web.

## Stack
- Node.js e Express
- JavaScript
- face-api.js / recursos de reconhecimento facial

## Como executar
Na raiz do repositório:

```bash
npm install
npm start
```

O script `start` executa `server.js` com nodemon. Acesse a aplicação no endereço local configurado pelo servidor.
