# Face Recognition with Registration

A study application combining registration and facial recognition with a Node.js/Express server. The backend exposes HTTP endpoints for the web interface.

## Stack
- Node.js and Express
- JavaScript
- face-api.js / facial recognition assets

## Run
From the repository root:

```bash
npm install
npm start
```

The `start` script runs `server.js` with nodemon. Open the local address configured by the server.
